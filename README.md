# Sales Order Dashboard Using Excel

## Project Overview

This is my Sales Order Dashboard project created using Microsoft Excel. The project analyzes sales data across different regions, countries, sales channels, and product categories.

## Objectives

* Analyze sales performance.
* Calculate revenue, COGS, gross profit, and gross margin.
* Summarize sales data using Pivot Tables.
* Visualize sales performance using charts and a dashboard.

## Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot Tables
* Charts
* Dashboard

## Dataset

The dataset contains 30 sales records with details such as order date, region, country, sales channel, product category, units sold, revenue, COGS, gross profit, and gross margin.

## Key Learnings

* Data organization and cleaning.
* Using Excel formulas for calculations.
* Summarizing data with Pivot Tables.
* Creating charts and dashboards.
* Analyzing sales performance.

## Conclusion

This project helped me improve my Microsoft Excel skills and understand the basics of sales data analysis and visualization.
